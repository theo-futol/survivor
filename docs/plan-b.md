# PLAN B

## Objectif

Anticiper ce qui peut casser pendant la démo et savoir quoi faire ou dire à ce moment-là.

## Fonctionnalités attendues à la semaine 1

- Catalogue des partenaires consultable (vrais partenaires, pas de données inventées)
- Espace salarié avec solde et historique
- QR code de paiement (statique)

## Points de blocage connus

- **Boutons non fonctionnels** : les boutons des espaces administration et partenaires sont visibles mais pas encore cliquables.
- **Connexion** : un bouton temporaire permet de se connecter directement avec un compte salarié pour la démo ; sinon, utiliser les identifiants du fichier `login.txt`.
- **Changement de couleur de fond** : non fonctionnel (problème de configuration du thème), correction prévue en semaine 2.

> **Avertissement :** l'affichage repose uniquement sur des données statiques. Aucune création, modification ou suppression de données n'est possible pour l'instant — prévu en semaine 2.
